# Lytics Analytics Dashboard

A static, executive-ready analytics dashboard for educational holding companies to compare brands, branches, and levels side-by-side. Built with React and Ant Design (via CDN) so it runs without a build step—just open `index.html` in a browser.

## Features
- Brand, branch, and level roll-ups with dynamic aggregation of verification, activation, and adoption metrics.
- Saved custom views per user (persisted in local storage) to tailor CEO or director lenses.
- Quick date presets (week/month/past 30/60/90/120 days) plus custom range picker.
- Side-by-side cards and tabular breakdowns for portfolio comparisons.
- Read-only experience suitable for senior leadership sharing.

## Getting started
1. Open `index.html` in a modern browser.
2. Use the segment switcher to toggle between brand/branch/level views.
3. Choose preset ranges or a custom date window to refresh adoption and staff performance metrics.
4. Save any selection as a reusable view for fast executive briefings.
